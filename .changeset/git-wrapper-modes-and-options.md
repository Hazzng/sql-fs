Sandbox git restores index-recorded modes on files it rewrites and honours `git -c`, `-C` and `--no-pager`. Branch switches that change only a file's mode remain unsupported. A cloned or checked-out `100755` file used to land as 0644, so `./gradlew` failed with "Permission denied" and the next `git add -A` committed a `100755 -> 100644` change nobody made (blindmansion/just-git#10). Mode restoration also runs after partial checkout failures and is best-effort so it preserves the git command's original result or error. Bump just-git to 1.9.1, which runs the command behind leading global options instead of printing help and exiting 0 (blindmansion/just-git#11). Bare `-c user.name` and `-c user.email` overrides require an explicit `=value`, so they cannot silently author a commit as `true`. `GIT_AUTHOR_*`/`GIT_COMMITTER_*` server settings are now git's fallback identity instead of sandbox env, so `git -c user.*`, repo `git config` and per-request `GIT_AUTHOR_*` env override them.

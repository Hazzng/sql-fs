## Codebase Patterns
- Test mocking: Use `vi.mock('./dialects/postgres.js', () => ({ PostgresDialect: vi.fn().mockImplementation(...) }))` to avoid real DB connections in unit tests; mock `transaction` with `vi.fn().mockImplementation(async (fn) => fn({}))` and `loadAllPaths` with `vi.fn().mockResolvedValue([])` so `SqlFs.ready()` completes without DB access.
- Env var cleanup in tests: Do NOT use `delete process.env.VAR` (biome noDelete lint) or `process.env.VAR = undefined` (sets it to string "undefined", not truly unset). Use `process.env.VAR = ""` for "effectively unset" — the factory checks `if (!databaseUrl)` which treats empty string as falsy.
- The branch for Phase 2 HTTP API is `ralph/phase2-http-api` (was on `ralph/phase1-sqlfs-postgres` at session start).
- `StorageBackend` type and `InodeKind` are exported from `src/fs/sql-fs/index.ts`.
- `InMemoryFs` is exported from `just-bash` (no constructor args required for default use).
